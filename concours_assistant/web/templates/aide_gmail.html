Google Alertes sans mot de passe

Un petit script tourne dans ton compte Google et envoie chaque matin tes alertes à ce site. Pas de validation en deux étapes, pas de mot de passe d'application.

Installation (5 minutes, une seule fois)

  1. Dans Chrome, ouvre le profil de ton Gmail dédié (pas la navigation privée).
  2. Ouvre script.new ↗ : un projet Google Apps Script vide s'ouvre.
  3. Efface tout le texte qui s'y trouve, puis colle le script (bouton Copier le script ci-dessous).
  4. Enregistre avec Ctrl+S (ou l'icône disquette).
  5. En haut, dans la liste des fonctions, choisis installer, puis clique ▶ Exécuter.
  6. Google demande l'autorisation : Examiner les autorisations → ton compte → Paramètres avancés → Accéder à Projet sans titre (non sécurisé) → Autoriser.
    Google affiche « non sécurisé » pour tout script qui n'a pas été publié : c'est le tien, tu peux lire son code ci-dessous. Il demande l'accès à Gmail parce que Google ne propose pas d'accès plus restreint pour ce type de script ; le code ne lit que le libellé « Concours » et ne modifie, n'envoie et ne supprime aucun email.
  7. En bas, le journal d'exécution affiche « … email(s) envoyé(s) au site ». Recharge cette page : « Dernier envoi reçu » s'affiche.

Ensuite, le script repart tout seul chaque jour vers 5 h, et le robot du site analyse les concours vers 7 h 15. Ne coche pas « Lire mes Google Alertes (IMAP) » dans ton profil : avec le script, ce n'est pas nécessaire.

Le script

Il contient l'adresse de ton site et ta clé d'import : elle permet seulement de déposer des alertes ici (ni lire tes données, ni te connecter). Ne la partage pas.
